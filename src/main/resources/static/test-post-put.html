🚀 API 接口测试工具

1. GET 请求测试

测试接口是否正常运行

GET http://localhost:8888/api/test/info

2. POST 请求测试 - 通用数据

发送任意 JSON 数据进行测试

POST http://localhost:8888/api/test/create

3. PUT 请求测试 - 更新数据

更新指定 ID 的数据

PUT http://localhost:8888/api/test/update/{id}

4. POST 请求测试 - 创建商品

模拟创建商品的请求

POST http://localhost:8888/api/test/product

5. PUT 请求测试 - 更新商品

更新指定 ID 的商品信息

PUT http://localhost:8888/api/test/product/{productId}
